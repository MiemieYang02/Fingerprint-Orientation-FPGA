# 基于 FPGA 的图像方向场计算与指纹特征分析系统

## 项目简介

本项目基于 FPGA（Field Programmable Gate Array，现场可编程门阵列）实现图像方向场计算与可视化系统，主要面向指纹图像的纹线方向分析与特征结构提取。

系统首先利用 Sobel 算子提取图像在水平方向和垂直方向上的梯度信息，得到梯度分量 Gx 和 Gy；随后通过 CORDIC（Coordinate Rotation Digital Computer，坐标旋转数字计算机）算法计算像素点的方向角；在此基础上，对图像进行局部块划分，并统计每个区域内的主方向，生成更加稳定的方向场结果。最终系统可将方向场结果进行可视化显示，为指纹图像结构分析提供基础。

## 项目目标

本项目的主要目标包括：

1. 在 FPGA 上实现 Sobel 梯度计算模块；
2. 根据梯度分量 Gx 和 Gy 计算图像局部方向；
3. 使用 CORDIC 算法实现硬件友好的方向角计算；
4. 对图像进行局部块划分和方向统计；
5. 生成稳定的指纹方向场结果；
6. 完成方向场结果的仿真验证与可视化分析。

## 系统整体流程

```text
输入灰度图像
      ↓
3×3 图像窗口生成
      ↓
Sobel 梯度计算
      ↓
输出 Gx / Gy
      ↓
CORDIC 方向角计算
      ↓
局部区域方向统计
      ↓
方向场生成
      ↓
可视化输出
